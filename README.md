# ASIKO — подготовка аудио для видеоигр по текстовому заданию

ASIKO — desktop-приложение для звукорежиссёра. Оно переводит текстовое задание на
русском («С 12-й по 16-ю секунду музыка из радио переходит в закадровую») в
проверяемые операции над дорожками, выполняет их локально и экспортирует результат в WAV.

Что умеет первая версия:

* **«Звук в сцене → закадровый»** и обратно: радио в комнате, телефонный динамик,
  удалённый источник, звук за препятствием → полное закадровое звучание. Отдельно
  настраивается, когда раскрываются частоты, меняется ширина, исчезает комната.
* **«Переход A → B»** между музыкальными треками: оценка темпа и долей с уверенностью,
  до трёх вариантов (короткое сведение, длинное сведение, завершение фразы), ручная
  правка точки входа, сравнение вариантов, явные конфликты темпа (темп и высота тона
  никогда не меняются).
* Точечные **текстовые правки** («Продли выбранный переход на 2 секунды», «Эффект радио
  убирай только в самом конце») с сохранением остальных решений; отмена/повтор всего.
* Прослушивание в контексте, петля, сравнение «результат / исходник / варианты»,
  выравнивание громкости только для мониторинга, индикация пиков и перегрузки.
* **Экспорт** WAV PCM 24 бит / 48 кГц (также 16 бит, 32 бит float, 44.1 и 96 кГц), весь
  проект или участок, с хвостами эффектов или без. Предпрослушивание и экспорт — один
  и тот же рендер (проверено побитово).

## Запуск готовой сборки

| ОС | Файл | Запуск |
|---|---|---|
| Windows 10/11 x64 | `ASIKO-0.1.0-windows-x86_64.zip` | распаковать, запустить `ASIKO-0.1.0-windows-x86_64\ASIKO.exe` |
| macOS 12+ на Apple Silicon (arm64) | `ASIKO-0.1.0-macos-arm64.dmg` | открыть образ, перетащить `ASIKO.app` в «Программы» |
| Linux x86_64 | `ASIKO-0.1.0-linux-x86_64.tar.gz` | распаковать, запустить `ASIKO-0.1.0-linux-x86_64/ASIKO` |

Python, Node.js и терминал не нужны. Mac на Intel эта версия не поддерживает: у llvmlite
(основа анализатора долей librosa/numba) нет сборок для macOS x86_64. Сборки не подписаны (нет сертификатов):

* **Windows** может показать SmartScreen «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».
* **macOS**: при первом запуске система сообщит, что не может проверить разработчика.
  Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть»
  (защиту ОС отключать не нужно). Подпись и notarization — см. `docs/DEVELOPMENT.md`.
* **Linux**: для звука нужен PortAudio (`libportaudio2`, обычно уже есть; библиотека также
  вложена в сборку). Без звуковой карты приложение работает в «тихом» режиме: курсор идёт,
  всё остальное доступно.

## Демонстрационные проекты

* **Из меню**: «Файл → Демо-проекты → Звук в сцене → закадровый» или «Переход A → B».
  Материалы синтезируются при первом открытии (≈10–30 с, включая анализ долей).
* **Из дистрибутива**: папка `Демо-проекты/` рядом с программой — откройте
  `Демо — звук в сцене.asiko` или `Демо — переход A-B.asiko` через «Файл → Открыть…».

Вся демонстрационная музыка сгенерирована программно (`src/asiko/testsignals.py`).

## Как пользоваться

### Сценарий «Звук в сцене → закадровый»

1. Перетащите музыку (WAV/FLAC/MP3, также OGG/AIFF) на шкалу или «Импорт аудио…».
2. Нажмите крупную кнопку **«Звук в сцене → закадровый»**, выберите источник
   («Радио в комнате»…), положение («Справа»), время (12–16 с). При необходимости
   отметьте «После конца перехода не менять» — участок будет защищён.
3. «Создать и прослушать» — переход играет с контекстом ±3 с.
4. В «Свойствах» справа — начальное и конечное состояние (усиление, панорама, ФВЧ, ФНЧ,
   ширина, доля обработанного звука, прямой звук, посыл в комнату) и таблица «когда меняется
   параметр»: свой интервал и форма кривой для каждого параметра, фиксация параметров.

Ограничение: обработка добавляет пространство и окраску, но не убирает их из записи —
из исходника с сильной реверберацией или узкополосной окраской чистое закадровое
звучание не восстановить.

### Сценарий «Переход A → B»

1. Импортируйте два трека (второй — перетащите на пустое место под первой дорожкой).
2. Нажмите **«Переход A → B»**, задайте примерное время. ASIKO оценит темп и доли
   (librosa) и покажет уверенность, затем предложит три варианта.
3. В «Свойствах» выберите вариант, поправьте вход B кнопками «±доля», «±такт», «±10 мс»,
   выберите хвост A: из исходной записи, без хвоста или добавленная реверберация (эффект).
4. «Сравнить варианты» — петля по зоне перехода; переключайте «Сравнение» в панели
   транспорта, «Выровнять громкость» — только для прослушивания.
5. Если разметка ошибочна — в свойствах клипа задайте темп и первую сильную долю
   вручную, кнопки «×2/÷2», «Сильная доля у курсора», «Граница фразы у курсора».

### Текстовое задание

Поле внизу окна. Без сети работает **локальный обработчик**: он понимает только типовые
шаблоны (кнопка «Шаблоны…»), а не произвольный русский язык, например:

```
Сделай переход с 12 до 16 секунды
Продли выбранный переход на 2 секунды            (или «до 18 секунды»)
Сдвинь выбранный переход на 1 секунду вправо
Перенеси раскрытие частот в конец
В выбранном переходе эффект радио убирай только в самом конце
Уменьши громкость выбранной дорожки на 3 дБ
Перейти с A на B примерно на 40-й секунде. B должен войти на сильную долю. Хвост A сохранить
Не меняй темп и высоту тона
Отмени последнее изменение
```

Конкретные команды выполняются сразу и отменяются кнопкой «Отменить это изменение» или
Ctrl+Z. При неоднозначности задаётся один вопрос с вариантами. «Сделай драматичнее» —
явно обозначенное художественное предложение, применяется только по подтверждению.
Просьба «убери ударные» объясняется: из стереомикса без отдельной дорожки это невозможно.

**Внешняя модель (необязательно).** «Настройки → Внешняя модель и аудио…»: провайдер
(Anthropic или OpenAI-совместимый сервер), адрес, модель, ключ. Ключ хранится в системном
хранилище (Windows Credential Locker, macOS Keychain); если его нет — только в памяти до
закрытия программы. Модели отправляется только текст задания и описание структуры проекта
(идентификаторы, времена, параметры); аудио, видео, пути к файлам не отправляются. Ответ
модели проходит ту же строгую проверку, что и локальные команды; ошибки сети не мешают работе.

### Защита и фиксация

* Клип: «Зафиксировать клип». Параметр: галочка «Фикс.» в таблице кривых. Переход: «Утвердить».
* Участок времени: выделите на линейке → «Правка → Защитить выделенный участок» — настройки
  в нём не будут меняться командами (хвосты эффектов соседних участков могут звучать внутри).
* Побитовая неизменность: «Правка → Зафиксировать выделенный участок в PCM» — участок
  хранится отрендеренным (float32) и при экспорте WAV 48 кГц не меняется ни на сэмпл.
  Не гарантируется при другой частоте экспорта или lossy-форматах.

### Проекты

Файл `.asiko` (JSON, формат версии 1) хранит ссылки на исходники и их SHA-256, дорожки,
клипы, переходы, варианты, ограничения и защищённые участки. Исходники не изменяются.
Сохранение атомарное, автосохранение — каждые 60 с (восстановление предлагается при запуске).
«Файл → Найти исходники…» ищет перемещённые файлы по размеру и контрольной сумме;
«Собрать переносимый проект…» копирует проект и все материалы в одну папку.

### Видео (необязательно)

«Файл → Подключить видео…» — синхронный просмотр без звука видео, «Начало на шкале» —
смещение. Набор кодеков зависит от ОС (Qt Multimedia/FFmpeg); при неподдерживаемом
кодеке выводится понятная ошибка, работа с аудио продолжается.

### Горячие клавиши

Пробел — воспроизведение/пауза · Home — в начало · L — петля · ←/→ — ±5 с ·
Ctrl+Z / Ctrl+Shift+Z (Ctrl+Y) — отмена/повтор · Ctrl+S / Ctrl+O / Ctrl+N ·
Ctrl+I — импорт · Ctrl+E — экспорт · Ctrl+1 / Ctrl+2 — сценарии · Ctrl+колесо — масштаб ·
Ctrl+0 — весь проект · Ctrl+F — показать переход · Del — удалить выбранное ·
M / S — mute/solo дорожки · Ctrl+Enter — выполнить задание · F1 — справка.

## Сборка из исходников и проверки

```bash
cd asiko
python -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements-dev.lock && pip install -e . --no-deps
python -m asiko                                    # запуск
python -m pytest                                   # 120 автотестов (≈4 мин)
python -m asiko --self-test                        # самопроверка на реальных файлах
python packaging/build.py                          # дистрибутив + самопроверка собранного приложения
```

Linux: для сборки и звука нужен `libportaudio2`. Подробнее — `docs/DEVELOPMENT.md`,
архитектура — `docs/ARCHITECTURE.md`, схема команд — `docs/COMMAND_SCHEMA.md`,
лицензии — `docs/THIRD_PARTY_LICENSES.md`, результаты проверок — `docs/TESTING.md`.

## Границы первой версии

ASIKO готовит аудиофайлы и переходы; интеграции с игровыми движками, генерации музыки,
клонирования голоса, разделения источников, плагинов DAW, облачных аккаунтов нет.
Растяжение времени и изменение высоты тона не выполняются. Художественную оценку
результата проводит звукорежиссёр — автоматические варианты являются предложениями.
