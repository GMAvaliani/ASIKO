# ASIKO — архитектура (ADR-0001)

Статус: принято. Дата: 2026-10-07.

## Задача

Desktop-приложение для звукорежиссёра игр: текстовое ТЗ на русском → проверяемые
операции над аудио → обработка, прослушивание, экспорт. Целевые ОС — Windows и macOS,
сборка и проверка — на доступной ОС (Linux), CI — для Windows/macOS.

## Выбранный стек

| Слой | Выбор | Причина |
|---|---|---|
| Язык | Python 3.13 | зрелые аудио- и научные библиотеки, быстрый цикл разработки, PyInstaller-упаковка |
| GUI | PySide6 6.11 (Qt 6, LGPL) | нативный desktop на Win/macOS, кастомная отрисовка таймлайна, QtMultimedia для видео |
| Декодирование/запись | soundfile 0.14 (libsndfile 1.2.2) | WAV/FLAC/MP3/OGG/AIFF чтение, WAV 16/24/32f запись; libsndfile встроен в колёса |
| Ресемплинг | python-soxr 1.1 (libsoxr, VHQ) | эталонное качество, явный вызов при импорте и экспорте |
| DSP | numpy 2.5 / scipy 1.18 | FFT-свёртка (oaconvolve), проектирование FIR (firwin2) |
| Анализ темпа/долей | librosa 1.0 (onset_strength, beat_track) | поддерживаемая библиотека; уверенность и сильные доли считаются поверх |
| Громкость | pyloudnorm 0.2 (ITU-R BS.1770) | выравнивание громкости только для мониторинга |
| Воспроизведение | sounddevice 0.5 (PortAudio) | callback в аудиопотоке, стабильная работа на Win/macOS |
| Секреты | keyring 25 | Windows Credential Locker / macOS Keychain / Secret Service |
| Упаковка | PyInstaller 6.22 | один каталог с интерпретатором и всеми библиотеками; пользователю не нужен Python |

Альтернативы: Electron/Tauri + Web Audio (сложнее обеспечить идентичность
предпрослушивания и экспорта и тестировать DSP), C++/JUCE (долгая разработка, нет
готового анализа долей). Python + Qt даёт полный контроль над офлайн-рендером при
приемлемой производительности (тяжёлые операции — в C внутри numpy/scipy/soxr,
GIL освобождается, интерфейс не блокируется).

## Слои

```
asiko/
  model/      модель проекта (dataclass), пресеты, автоматизация, сериализация формата v1
  commands/   версионированная схема команд asiko.plan/1, валидатор, транзакции,
              undo/redo, защищённые участки, генератор вариантов перехода A→B
  audio/      импорт/декодирование/ресемплинг, кэш исходников, пики, анализ,
              DSP-блоки, рендер (единый для прослушивания и экспорта), экспорт,
              фиксация участков в PCM, воспроизведение
  nlp/        локальный обработчик шаблонов, адаптер внешнего LLM, хранилище ключей
  storage/    сохранение/открытие (атомарно), автосохранение, поиск исходников,
              переносимый проект
  ui/         интерфейс Qt: таймлайн, библиотека, транспорт, инспекторы, сценарии,
              поле задания, история, экспорт, настройки, видео
```

Поток изменения: текст → `Plan` (asiko.plan/1) → строгая проверка схемы → семантическая
проверка на копии проекта (ссылки, диапазоны, блокировки, защищённые участки) →
транзакция (снимок до/после в истории) → рендер изменившихся фрагментов → прослушивание.
Ручные действия в интерфейсе проходят тот же путь (origin = "ui").

## Ключевые решения по DSP

* Вся внутренняя обработка — float64 в блоках, кэш и шина — float32. Исходники
  ресемплируются в частоту проекта (по умолчанию 48 кГц) явно, soxr VHQ.
* Все блоки с памятью — КИХ (FIR): фильтры с линейной фазой и свёрточная реверберация.
  Поэтому выход на любом интервале — чистая функция входа в окне конечной длины.
  Рендер идёт фрагментами по фиксированной сетке (2^18 сэмплов) с нужным
  предшествующим и последующим контекстом; один и тот же фрагмент всегда
  вычисляется одинаково — предпрослушивание и экспорт побитово совпадают,
  кэш корректно инвалидируется по зависимостям фрагмента.
* Автоматизируемый фильтр — банк линейно-фазовых КИХ на сетке 1/12 октавы с
  интерполяцией весов по сэмплам. Все ядра одной длины → одинаковая задержка →
  смешивание без гребенчатых провалов; задержка компенсирована.
* Прямой и обработанный сигналы смешиваются с компенсированной задержкой
  (когерентное линейное смешивание). Реверберация получает моно-посыл и
  возвращает декоррелированное стерео (моносовместимость).
* Параметры вычисляются по каждому сэмплу из аналитических кривых (без «ступенек»);
  минимальная длительность изменения 10 мс; края клипов — анти-щелчковые фейды.
* Лимитер и нормализация не включаются без явного выбора пользователя.

## Ограничения подхода

* Растяжение времени и изменение высоты тона не реализованы (и не требуются);
  ограничения «не менять темп/высоту» соблюдаются всегда, конфликты показываются.
* Разделение источников не реализовано: для отдельного удаления ударных нужен стем.
* Видео — только синхронный просмотр через QtMultimedia (набор кодеков зависит от ОС
  и сборки FFmpeg в Qt).
