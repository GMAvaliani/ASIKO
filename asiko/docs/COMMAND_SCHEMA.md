# Схема команд asiko.plan/1

Текст пользователя → **план** (JSON) → строгая проверка → транзакция на копии проекта →
DSP → прослушивание. Одинаково для локального обработчика (`origin: "local"`), внешней
модели (`"llm"`) и ручных действий в интерфейсе (`"ui"`). Полная JSON Schema —
[`plan.schema.json`](plan.schema.json); проверка реализована в `src/asiko/commands/schema.py`
(типы, диапазоны, лишние поля), ссылки и совместимость — в `commands/handlers.py` и
`commands/protection.py`.

## План

```json
{
  "schema": "asiko.plan/1",
  "base_revision": 12,
  "origin": "local",
  "kind": "edit",
  "artistic": false,
  "text": "Продли выбранный переход на 2 секунды",
  "operations": [
    {
      "op": "space.set_timing",
      "target": {"transition_id": "spc_1a2b3c4d"},
      "time": {"coord": "relative", "unit": "s", "end_delta": 2.0},
      "preconditions": [{"kind": "exists", "id": "spc_1a2b3c4d"}]
    }
  ]
}
```

* `kind`: `edit` (применяется сразу, отменяется), `proposal` (только по подтверждению;
  `artistic: true` — художественное предложение), `question` (уточнение с вариантами-планами),
  `info` (объяснение, без изменений), `undo` / `redo`.
* `base_revision` — версия проекта, на которой сформирован план. Если проект изменился,
  план **проверяется заново** и применяется только после подтверждения пользователя;
  ссылки на удалённые объекты дают ошибку.
* Любая ошибка — проект не меняется (транзакция атомарна).

## Операция

| Поле | Назначение |
|---|---|
| `op` | тип операции (таблица ниже) |
| `target` | идентификаторы дорожки/клипа/перехода/исходника |
| `time` | время: `coord` — `timeline` (секунды шкалы), `relative` (сдвиг), `transition` (секунды от начала перехода), `transition_fraction` (доля 0..1), `transition_end` (секунды до конца, ≤ 0), `source`; `unit` — `s` или `fraction`; `start`, `end`, `at`, `delta`… |
| `params` | параметры с единицами: дБ (`gain_db`, `reverb_db`, `direct_db`), Гц (`hp_hz`, `lp_hz`), панорама −1…+1, ширина 0…2, доля 0…1, кривые `{start, end, shape}` |
| `constraints` | `protect_after` / `protect_range` (защищённые участки), `keep_tempo`, `keep_pitch` |
| `preconditions` | `exists`, `not_approved`, `revision`, `duration_at_least` |

## Операции

| Операция | Назначение | Доступна модели |
|---|---|---|
| `space.create` | Создать переход между двумя состояниями звучания (в сцене ↔ закадровый) на дорожке | да |
| `space.set_timing` | Изменить начало/конец перехода (абсолютно или сдвигом) | да |
| `space.set_curve` | Изменить, когда и как меняются параметры внутри перехода | да |
| `space.set_state` | Изменить начальное (from) или конечное (to) состояние перехода | да |
| `space.set_slope` | Крутизна фильтров перехода | да |
| `space.delete` | Удалить переход | да |
| `transition.lock_params` | Зафиксировать/разблокировать отдельные параметры перехода | да |
| `transition.approve` | Утвердить (заблокировать) переход или снять утверждение | да |
| `music.create` | Создать переход между двумя музыкальными клипами A → B с вариантами | да |
| `music.select_variant` | Выбрать вариант перехода A → B | да |
| `music.set` | Ручная правка активных параметров перехода A → B | да |
| `music.delete` | Удалить переход A → B (клипы возвращаются на места) | да |
| `track.add` | Добавить дорожку | да |
| `track.set` | Изменить дорожку: громкость, mute, solo, имя | да |
| `track.delete` | Удалить дорожку вместе с клипами | да |
| `clip.add` | Поместить импортированный исходник на дорожку | да |
| `clip.move` | Переместить клип (связанные переходы переносятся вместе с ним) | да |
| `clip.set` | Изменить клип: усиление, фейды, границы, блокировку | да |
| `clip.delete` | Удалить клип с дорожки | да |
| `constraint.set` | Ограничения проекта: не менять темп / высоту тона | да |
| `protect.add` | Защитить временной участок от изменения настроек | да |
| `protect.remove` | Снять защиту участка | да |
| `beats.set` | Задать сетку долей исходника (ручная разметка или результат анализа) | да |
| `beats.shift` | Сдвинуть сетку долей исходника | да |
| `phrases.set` | Задать границы музыкальных фраз (время исходника) | да |
| `freeze.add` | Зафиксировать участок в отрендеренный PCM | только интерфейс |
| `freeze.remove` | Снять фиксацию PCM | да |
| `video.set` | Подключить видео для просмотра | только интерфейс |
| `video.offset` | Смещение видео на шкале | да |
| `video.clear` | Отключить видео | да |
| `project.rename` | Переименовать проект | да |
| `source.add` | Добавить исходник в библиотеку (из интерфейса) | только интерфейс |
| `source.relink` | Обновить путь к перемещённому исходнику | только интерфейс |
| `source.remove` | Удалить неиспользуемый исходник из библиотеки | да |

Операции «только интерфейс» (пути к файлам, фиксация PCM) внешней модели недоступны:
план с ними от `origin: "llm"` отклоняется. Модель не выполняет команды ОС, не генерирует
код и не обращается к файловой системе — она только предлагает план.

## Проверки после операций

* Инварианты: клипы в пределах исходников, переходы на одной дорожке не пересекаются,
  кривые в пределах перехода (минимальное изменение 10 мс).
* Блокировки: зафиксированные клипы и параметры, утверждённые переходы и варианты.
* Защищённые участки: «отпечаток» эффективных настроек участка (все параметры по сетке
  1 мс, состав и привязка клипов, огибающие, уровень дорожки) до и после должен совпасть.
  Изменения рядом с участком дают предупреждение о хвосте эффектов.
* Зафиксированные в PCM участки: предупреждение, что изменения в них не слышны.

## Сводка изменения

Каждая транзакция возвращает краткое описание, например:
«Переход: 12 с–18 с. Раскрытие частот: 16 с–18 с (последние 2 с перехода). Длительность
перехода, положение клипов и остальные параметры сохранены.»
