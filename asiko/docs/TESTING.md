# Проверки ASIKO

Все тестовые материалы создаются программно (`src/asiko/testsignals.py`): тоны, импульсы,
шум с фиксированным seed, клик-треки с известным темпом и акцентом сильной доли,
синтезированные музыкальные фрагменты (аккорды, бас, ударные, мелодия). Чужая музыка
не используется. Все тесты работают в путях с кириллицей и пробелами
(`…/Проекты ASIKO/тест 1/…`), без сети и без ключа модели.

Запуск: `python -m pytest` (offscreen Qt). Самопроверка: `python -m asiko --self-test`.

## Сквозные сценарии (раздел 15 ТЗ)

`tests/test_acceptance.py` выполняет их через окно приложения (мастера, поле задания, кнопки
инспектора, меню, диалог экспорта):

* **A** — импорт чистой музыки → «Радио в комнате, справа» 12–16 с → «Создать и прослушать»
  (проверяется, что до перехода звук смещён вправо, после — по центру) → «Продли выбранный
  переход до 18 секунды» → «Перенеси раскрытие частот в конец» → Ctrl+Z / Ctrl+Shift+Z →
  сохранение → открытие в новом окне → экспорт WAV 24/48.
* **B** — два трека (FLAC 44.1 кГц и WAV 48 кГц, 120 и 100 BPM) → мастер «Переход A → B» с
  «не менять темп и высоту» → анализ долей → 3 варианта, конфликт темпа у длинного →
  выбор варианта «завершение фразы» → правка входа (+1 доля, −10 мс) → «Сравнить варианты»
  (буферы трёх вариантов, переключение, выравнивание громкости) → экспорт выбранного
  варианта (участок перехода с контекстом).
* **C** — сеть отключена (подмена `socket`) → сценарий A только локальными командами,
  отмена/повтор, уровень дорожки, сохранение, экспорт → внешняя модель с недоступным
  адресом: понятная ошибка, проект не изменён, локальное предложение требует подтверждения →
  сценарий B через мастер → сохранение и экспорт.

## Что не проверено

* **Реальное прослушивание** не выполнялось: в среде нет звуковой карты (PortAudio видит
  только null-устройство ALSA). Проверялись сигналы (уровни, спектр, панорама, время,
  отсутствие щелчков по второй разности), а не художественное качество.
* Художественная оценка вариантов перехода и пресетов техническими тестами не подменяется.
* Сборки Windows/macOS проверены только в GitHub Actions (тесты, сборка, самопроверка
  собранного приложения с offscreen-интерфейсом); на реальных машинах с этими ОС приложение
  вручную не запускалось, окно глазами не осматривалось, звук через динамики не проверялся.
