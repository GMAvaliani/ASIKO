# ASIKO — сторонние компоненты и условия распространения

Дистрибутив ASIKO включает интерпретатор Python и перечисленные библиотеки. Тексты
лицензий, найденные в метаданных пакетов, копируются при сборке в папку `licenses/`
рядом с этим файлом. Версии зафиксированы в `requirements.lock`.

Не включаются: scikit-learn (не используется в анализе долей), Qt WebEngine и прочие
неиспользуемые модули Qt (исключены при сборке).

Демонстрационная и тестовая музыка синтезируется программно (`asiko/testsignals.py`);
чужие записи не используются.
